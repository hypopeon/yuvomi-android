# 0011. Strings come from upstream

**Status:** Accepted, 2026-11-01

## Context

Upstream ships 27 locales in `public/locales/<locale>.json`: nested JSON, `{{name}}` placeholders,
and plural variants as CLDR-suffixed keys (`key_one`, `key_few`, `key_many`, `key_other`; Polish
uses all four). `public/i18n.js` resolves them with `Intl.PluralRules`, and post-processes Korean
particles. Translating the same UI
again in `strings.xml` would drift from upstream on every release and would cover fewer languages.

## Decision

- The app loads its UI strings at runtime from `app/src/main/assets/i18n/<locale>.json`,
  generated by the sync tooling from upstream's locale files.
- Only the namespaces the app uses are extracted (listed in `upstream/i18n-namespaces.txt`),
  which keeps the assets small and the diffs readable.
- Strings that exist only in this app live in `app/src/main/assets/i18n-android/<locale>.json`
  under the `android.` prefix, English first.
- Lookup order matches upstream: chosen locale, then English, then the key itself.
- The UI language is a **per-device** choice, as in the PWA (upstream keeps it in the browser's
  `localStorage`, not on the account). Default is the device locale, mapped with the same rules
  as upstream's `i18n.js` (`zh-TW` to `zh-Hant`, `no` to `nb`, and so on); the user can override
  it in the app.
- Plurals: when a `count` argument is present, try `key_<category>` with the category from
  `android.icu.text.PluralRules` for the locale, then `key_other`, then `key`, exactly upstream's
  `resolvePluralKey` order.
- Placeholders: `{{name}}` is replaced; a `{{name}}.` whose value already ends in a full stop
  keeps one full stop, as upstream does. Korean particle resolution is ported from
  `public/utils/korean-particles.js` and covered by tests that reuse upstream's cases.
- Layout direction is RTL for `ar` and `fa`.
- `strings.xml` holds only what Android itself reads: the launcher label.
- A unit test fails when the code references a key that is missing from `en.json`.

## Consequences

- The app speaks every language the PWA speaks, with the same words.
- A key renamed upstream becomes a failing test in the weekly sync PR rather than a raw key on
  screen.
